# Domain Docs

## Layout

This is a single-context project:

- CONTEXT.md at the repository root.
- Architecture decision records under docs/adr/.

## Consumer rules

Before exploring, read CONTEXT.md and relevant ADRs.
If CONTEXT-MAP.md exists later, follow its relevant context links.

If domain documents do not exist, proceed silently.
Create them lazily through domain-modeling work.

Use the domain glossary's vocabulary consistently.
Note genuine glossary gaps for future domain modeling.

Explicitly surface any conflict with an existing ADR.
